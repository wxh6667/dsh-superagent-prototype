# 目标

管理面板不再出现 GitHub/Feishu 相关的来源卡片、字段、链接、线程/触发/票据专用展示与文案；本地源界面保持可用。

# 要求

- `src/client/*` 中来源、概览、线程、触发、票据、设置、部署与标记相关代码移除 GitHub/Feishu 分支、链接与专用图标/文案。
- `locale/en.json`、`locale/zh.json` 删除不再使用的条目；新增文案与现有风格一致。
- 若 API 路由随上一子任务调整，同步 `src/client/api.ts` 类型与页面数据读取。
- 更新面板测试与快照，确保本地源页面仍可渲染。

# 验收

- 面板不显示 GitHub/Feishu 入口、配置或链接；设置页只剩本地仓库配置。
- 本地源的线程、票据、触发页面正常渲染，现有面板测试通过。
- `scripts/verify.sh` 通过；UI 改动附 Before/After 截图（同一页面、同一视口、同一主题），标注基线版本与改动版本。

# 范围外

不改启动页表单；不改服务端行为。
