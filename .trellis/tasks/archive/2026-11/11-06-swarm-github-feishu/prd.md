# 目标

1. 新建 swarm 只需填写任务目标、选择工作区；其余参数走默认，创建后主会话立即收到简报并开始工作，不再出现空白会话页。
2. 彻底移除 GitHub 与 Feishu 来源：源码、配置、安装字段、策略、轮询、订阅通知、外链、线程读取、专用提示词与 skill、文档与面板展示，只保留本地源。

# 验收

- 启动页必填项仅为任务目标与工作区；工作区来自已注册工作区下拉，可手动输入兜底；高级项默认折叠。
- 创建后自动进入该 swarm 的主会话，会话中已有任务简报作为第一条消息并开始响应。
- 仓库与运行时不再存在 GitHub/Feishu 入口、配置、轮询、订阅或 skill；面板只显示本地源。
- schema 13 迁移删除非本地来源的历史记录，本地记录不受影响；迁移前自动备份数据库到 state 目录 `backups/`。
- `scripts/verify.sh` 通过；UI 改动附同场景 Before/After 截图。

# 范围外

- 不改 Trellis 规划/派发/工具体系与 worker 流程，不引入新依赖。
- 不移除通用 Thread/Ticket 机制与本地源。

# 风险

历史数据清理不可恢复，用户已明确授权；实现必须先备份再迁移。子任务按 1→2、1→3 顺序推进，避免 http/api/locale 冲突。

# 追加需求（16:11 确认）

- 工作区：子任务 worktree 会各自注册一个 DSH 工作区。这些工作区在 swarm 结束时统一清理注册（目录与会话日志保留），且启动页工作区下拉只列出长期使用的工作区。
- 可见性：主会话页顶部新增状态条，显示当前 swarm 的在跑、待跑与刚结束任务，避免用户不知道后台在做什么。

# 追加需求（16:21 确认）

- 主项目与子项目模型分开配置：新建 swarm 时可分别选择主会话模型与子任务模型，下拉选择，默认「继承全局设置」；未选择时沿用现有全局设置。
