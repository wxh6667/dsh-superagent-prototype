# 目标

新建 swarm 只需「任务目标」与「工作区」两项，创建后主会话立即收到简报并开始工作。

# 要求

- 启动表单必填项为任务目标与工作区；标题由目标首行自动生成（截断到既有上限），可在高级选项中修改。
- 工作区为下拉选择，选项来自已注册工作区；默认选中本地仓库；提供手动输入路径以支持未注册目录。
- 验收标准、写入范围、verify、prepare 与预算收进默认折叠的高级选项，默认值与现有行为一致。
- 创建成功后把简报（目标、工作区，以及已填写的验收、范围、预算、verify）作为第一条消息投递给该 swarm 的主会话，使会话页不空白并开始响应；消息只呈现用户填写的内容，不追加额外要求。
- 工作区列表由服务端从工作区注册表读取，不引入新依赖。
- 空目标、空工作区的行内校验保持清晰。

# 验收

- 只填目标、选工作区即可创建成功；下拉可用并默认本地仓库；手填路径仍可用。
- 创建后进入主会话，会话中已有任务简报消息并开始响应。
- 现有 swarm 创建校验、legacy 只读行为不变；`scripts/verify.sh` 通过。
- UI 改动附同场景、同视口、同主题的 Before/After 截图，标注基线版本与改动版本。

# 追加需求（16:11 确认）

- 工作区下拉只列长期使用的工作区，排除 swarm 运行期间新建的临时工作区（数据由工作区清理子任务提供）。
- 主会话页顶部新增状态条：显示当前 swarm 的在跑、待跑与刚结束任务及最近变化；按会话所属 swarm 显示，非 swarm 会话不显示。状态条注册到 DSH 的 `conversation.header` 插槽，随任务变化刷新。

# 范围外

不改 Trellis、派发工具与 worker 流程，不改来源体系。
