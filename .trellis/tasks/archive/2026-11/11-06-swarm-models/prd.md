# 目标

每个 swarm 可以单独指定主会话模型与子任务（执行器）模型，通过下拉选择，默认继承全局设置。

# 要求

- Swarm 增加两个可选模型字段：主会话模型、子任务模型；缺省表示继承全局设置，已有 swarm 不受影响。
- 启动页创建表单的「高级选项」中提供两个模型下拉：默认项为「继承全局设置」，其余为当前可用的 provider / model 组合；选择后随创建请求保存。
- 会话建立时按 swarm 解析：主会话使用 swarm 覆盖值，否则沿用全局主 Session 设置；执行器会话使用 swarm 覆盖值，否则沿用全局执行器设置。已有会话保持其原选择。
- 下拉数据来自现有模型目录接口，不引入新依赖；无可用目录时给出手动输入或明确的不可用提示，不得静默保存空值。
- 会话页或 swarm 行能看出当前使用的是继承还是覆盖，避免误解。

# 验收

- 新建 swarm 不选模型时，主/子会话与改动前行为一致（继承全局）。
- 选择覆盖后，新主会话与新子任务会话分别使用所选模型；已存在会话不受影响。
- 下拉是真正的选择控件，含「继承全局设置」项；保存失败有明确错误。
- `scripts/verify.sh` 通过；UI 改动附同场景、同视口、同主题的 Before/After 截图。

# 范围外

不改全局设置的语义；不改来源体系与 Trellis 流程。
